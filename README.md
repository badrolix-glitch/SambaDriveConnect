Version 0.1.0 Description
This is a simple program for connecting a Samba share to your PC without needing to know the commands. It offers a user-friendly interface where you simply enter the server address, username, and password to connect. You can also automate this process (additional checkbox), and the share will connect automatically when you turn on your PC (if you so choose).

Launching the Program
Unzip the archive and simply run the "SambaDriveLinux" file.

Additional Information
This release is one of the first versions of the program; it may contain bugs and is quite crude. However, it includes .NET in the package, so you won't need to install it separately on your computer.
I'll post an ARM64 version later if you need it.
